# 前后端接口约定

前端已按本约定开发，并用 MSW 模拟后端跑通。后端（FastAPI）实现时，响应结构以 `frontend/src/api/types.ts` 为准。实现完成后导出 OpenAPI，与该文件逐项核对。模拟实现 `frontend/src/mocks/handlers.ts` 可以当作行为参考。

FastAPI 实现位于 `src/socialdog_agent/server/`，运行及数据准备见 [多人工作台部署](多人工作台部署.md)，导出的契约见 [openapi.json](openapi.json)。未配置正式题库时返回空数组。模型未提供用量、调用中断或价格尚未填写时，相应 token/估算费用为 `null`，前端展示“—”，不能替换为0。

## 通用规则

- 所有接口都在 `/api` 下，返回 JSON。出错时返回非 2xx 状态码和 `{"error": "给用户看的中文说明"}`。错误信息不能带本地路径、SQL 或密钥。
- 写入请求按实际接收字节限制大小，包含分块上传：普通请求64KiB、评分及批量问题反馈1MB、题库草稿2MB；超出返回413。字段长度和条数仍按接口模型校验。
- 登录态使用 HttpOnly + Secure + SameSite=Lax 的会话 cookie。前端请求带 `credentials: same-origin`。
- CSRF：`/api/me` 和登录响应里返回 `csrf_token`。除登录和接受邀请外，所有非 GET 请求都必须带请求头 `X-CSRF-Token`，不匹配时返回 403。
- 状态码约定：未登录 401；没有权限或 CSRF 失败 403；资源不存在 404；状态冲突 409（已有任务在跑、重复打分、用户名重复）；配额用完 429。
- 时间一律用带时区的 ISO 8601 格式，日期用 `YYYY-MM-DD`，金额单位为元。

任务排队规则：全站最多同时运行 `max_concurrent_jobs` 个，每人最多 `per_user_concurrent_jobs` 个。排队中的任务返回 `status: "queued"` 和 `queue_position`。服务重启后，未完成的任务标记为 `error`。

## 数据核对（按角色授权，不经过模型）

| 方法 | 路径 | 请求 | 响应 |
| --- | --- | --- | --- |
| GET | `/api/reference/meta` | 可选上下文 `attempt_id/assignment_id/bank_version_id`（最多一个） | `ReferenceMeta` |
| GET | `/api/reference/query` | 查询参数 `scope, by, start_date, end_date, product` 及上述上下文 | `ReferenceResult` |

这两个接口只读 `reference.sqlite`。普通查询中研究员仅可查询 ≤T 的行，日期范围和商品列表也仅来自 ≤T；管理员可以查询完整历史。已提交测评的限定例外见下文。不能通过查询参数伪造权限。`ReferenceMeta.can_view_after_cutoff` 表示本次上下文是否允许 T 后数据。

没有额外授权窗口时，完全位于 T 后的研究员查询返回空结果，跨 T 查询只返回 ≤T 的部分。核对 CSV 在浏览器中从此接口结果生成，遵循同样边界；管理员评分 CSV 仍仅管理员可访问。**核对接口永远不能注册成 agent 工具。**

跨越 T 的同名分组拆为两行，分别标记 `after_cutoff=false/true`；前端行键须包含该标记。核对库必须与截断包同源，首次部署的截止日期一致，后续发布使用题库版本的T。

`allow_post_cutoff_reference_after_submit` 默认false。开启后，仅本人已提交的 `attempt_id` 可额外读取该题 `post_cutoff_reference` 的日期/商品窗口；没有窗口不解锁。一般查询不解锁，所有上下文均服务端校验，不能借他人作答或任意旧版本越界。关掉开关后即时撤销额外访问。待办与作答的核对使用其固定版本T。

## 后台配置模块

| 方法 | 路径 | 请求/响应 | 权限与行为 |
| --- | --- | --- | --- |
| GET | `/api/admin/question-bank` | `BankWorkspace` | 管理员；草稿、当前和历史已发布版本、可生成T的日期范围 |
| PUT | `/api/admin/question-bank/draft` | `BankDraft` → `BankWorkspace` | 管理员；带revision防止覆盖并发编辑，保存后revision加1 |
| POST | `/api/admin/question-bank/publish` | `{revision}` → `BankWorkspace` | 管理员；检验题目/核对窗口、生成截断包、原子启用版本，草稿为空不可发布 |
| GET | `/api/research-policy` | `ResearchPolicy` | 登录用户；表单、审核参考标准及模式开关 |
| PATCH | `/api/admin/research-policy` | `ResearchPolicy` → `SiteSettings` | 管理员；仅更新研究规则，保持额度等其他设置 |
| PATCH | `/api/admin/settings` | `RuntimeSettings` → `SiteSettings` | 管理员；额度与运行模块使用，保持题库和研究规则 |
| GET | `/api/review/members` | `ReviewMember[]` | 管理员或任一审核权限；只返回id和显示名 |
| GET | `/api/admin/model-settings` | `ModelServiceSettings` | 管理员；仅返回provider、configured和updated_at，不返回密钥 |
| PUT | `/api/admin/model-settings` | `{api_key}` → `ModelServiceSettings` | 管理员；验证通过后保存，新任务立即使用，失败保留旧密钥 |
| POST | `/api/admin/model-settings/check` | `ModelServiceSettings` | 管理员；验证已保存凭证，不计提问额度 |
| DELETE | `/api/admin/model-settings` | `ModelServiceSettings` | 管理员；停用新的模型任务，重启后保持停用 |

模型服务提供商固定DeepSeek，不接受客户端设置API地址或其他提供商。密钥输入使用write-only字段，校验失败不回显请求内容，保存于服务端私有文件。模型服务请求都需登录，变更及检查需CSRF。凭证不属于普通SiteSettings或研究员可读的ModelCatalog。

`NewUser/UserPatch.permissions` 可配置 `review_feedback`、`review_ideas`、`view_researchers`，`Me/AdminUser` 返回该列表。普通角色仍为 `researcher`，审核权限不授予账号管理、题库发布、全站配置或完整数据访问。`max_accounts` 默认10，`default_daily_limit/default_evaluation_reserve` 默认30/0；默认值只对新成员生效。

A/B模式按作答受理时的 `anonymous_ab_evaluation` 固定。未评分时 `EvalAttempt.turn.result=null`，仅返回无来源的 `answer_panels`；`RatingInput.anonymous_scores` 必须同时含A和B两套 `RatingScores`，不得同时填普通scores或附加问题反馈。提交后揭示模型结果、依据及面板来源，`Rating.scores` 为映射后的模型评分，同时保存两组匿名评分。普通模式保持原scores输入。开启模式前的作答不变；来源揭示前问题反馈接口返回409。

`evaluation_reserve` 可在创建/更新成员时配置，范围0至每日上限；省略时用站点默认值。`Quota.chat_remaining_today` 是对话剩余额度，`remaining_today` 是包含测评可用预留的总剩余；全站限制始终适用。两种可选模式均默认关闭，由管理员在研究规则中配置。
